# CopyStroke

**CopyStroke** is a mini web tool designed to process 256x256 pixel images and convert them into JSON data for use in Basepaint. This app allows you to download the daily color palette and also upload your drawings to get JSON data for use in Basepaint.

<img src="https://github.com/user-attachments/assets/d5eeed30-c85c-4fea-ac10-615abf5e0e98" width="400"/>


## Features:
- **Daily Palettes**: Download a dynamically generated daily color palette as a PNG file.
- **Image Upload**: Upload 256x256 pixel images for analysis.
- **Color Processing**: Converts image colors into JSON data.
- **Clipboard Copy**: Copy processed data to the clipboard with one click.

## How to Use:
1. **Download the Daily Palette**:
   - Click "Download Today Palette .png" to get the daily color palette.
2. **Upload an Image**:
   - Click the "Load Image" button and select a 256x256 pixel image.
   - The image will be displayed in the preview area.
3. **Process the Image**:
   - Click the "Copy Stroke" button to process the image and copy the data to the clipboard.


## Technologies Used:
- **HTML5**: For the structure of the application.
- **CSS3**: For custom styles and responsive design.
- **JavaScript**: For image processing, event handling, and palette generation.
- **Service Workers**: To support Progressive Web App (PWA) functionality.
